# v0.1.20 — Reliable recovery, Gemini 4 and reference cost estimates

Tested with Pi 1.5.2 and Node.js >=22.19.0. ACP SDK 2.6.0 continues to negotiate **ACP protocol 1**, not experimental protocol v2. The signed runtime catalog now includes Antigravity ACP 1.5.0. Permission defaults are unchanged.

## Features

- Support Gemini 4 Hydrogen and its advertised `xhigh` reasoning tier, with catalog rates for Hydrogen and Carbon. Unsupported programmatic effort choices fall back to supported tiers (#103).
- Show reference token-cost estimates for known Gemini model families instead of always reporting zero. These estimates use catalog rates, including cache discounts and the supported long-context tier; they are **not Antigravity subscription charges**. Unknown model families keep zero rates (#88).
- Configure native tool activity with `/antigravity-acp tool-activity [off|compact|full]`. The persisted default is `compact`: one line when a tool starts; `off` hides tool activity and `full` includes updates and details (#104).

## Reliability fixes

- Detect closed ACP transports immediately, evict dead bindings before a retry begins, preserve consumed continuation checkpoints, and include redacted stderr details in timeout errors (#99).
- Bound warm bindings with a default capacity of four and five-minute idle expiry. Keep active prompts and parked tool/permission requests, preserve saved records for restoration, and guard session-setup/shutdown races (#102).
- Recover Pi tool results that arrive after the ACP prompt ends, while keeping cancellation available. Throwaway requests no longer retain or save ACP sessions (#90, #85).
- Reconcile ACP 1.5.0 net-input and inclusive-thought usage with older usage formats. Avoid premature context-overflow detection on tool-heavy, multi-inference turns (#101, #89).
- Separate reconstructed history from the current user request, and prevent user text such as `/plan`, `/usage` or `/logout` from being executed as an Antigravity command (#96, #86).
- Fail bounded, repeated `429 RESOURCE_EXHAUSTED` retries instead of waiting for the full inactivity timeout. Quota errors do not trigger automatic Pi retries, and the stuck agent process is closed (#97).
- Remove the 64-tool projection cap while retaining schema/name validation. Send increasing MCP progress notifications during waiting tool calls that request progress, and close open HTTP connections during bridge shutdown (#100).
- Update Pi development dependencies to 1.5.2, ACP SDK to 2.6.0, and other compatible dependencies; refresh the signed runtime catalog through ACP 1.5.0 (#94, #95, #87, #92, #91).

## Validation

- Clean installation, typechecking, and **457 ordinary tests** pass; eight opt-in official-runtime/live tests remain skipped.
- Package dry runs and isolated packed-install smoke tests pass with the bundled npm CLI and npm 12.
- Full dependency audit reports **zero vulnerabilities** at release validation time.
- CI checks Node 22.19.0 and 24. Publication uses the existing npm trusted-publishing/OIDC workflow without a long-lived npm token or protection bypass.

No authenticated inference, fresh OAuth login, native macOS keychain test, or Windows qualification was performed during release validation. Model discovery does not establish account eligibility. The provider is not a sandbox.
